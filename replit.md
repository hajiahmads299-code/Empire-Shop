# Empire Shop

## Project overview

Empire Shop is a Next.js 15 e-commerce application with Prisma/PostgreSQL, multilingual storefront support, buyer and seller flows, admin APIs, payments and seller finance.

## Current delivery scope

Stage 2 focuses on backend, database integrity, repositories, services, API validation, transaction safety, concurrency and production verification. UI/UX and frontend behavior are intentionally preserved.

## User preferences

- Do not change UI/UX or enter Stage 3 unless explicitly requested.
- Prefer minimal, targeted backend changes over broad rewrites.
- Report database, build and API verification results explicitly.
